# Raw Dataset

Place the original Retailrocket dataset files in this directory.

Expected files:

- events.csv
- item_properties_part1.csv
- item_properties_part2.csv
- category_tree.csv

The raw datasets are excluded from Git version control because of their large size and redistribution considerations.

Download the dataset from:
https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset

Keep the original source files unchanged.
